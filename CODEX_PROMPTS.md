# Useful Codex Prompts

## Create a new website
Build a complete responsive website from the current starter. Keep the code dependency-free, use semantic HTML, reuse CSS tokens, and run `npm run check` and `npm run build` before finishing.

## Modify an existing website
First inspect the current structure and identify the smallest safe set of files to change. Preserve existing content and links unless I explicitly ask otherwise. Implement the requested visual/content changes, then run checks and build.

## Import my current website
I will provide exported HTML/CSS/JS and assets. Place source files under `src/`, normalize asset paths, keep SEO metadata, remove broken third-party dependencies where possible, and make the result runnable with `npm run dev`.

## B2B landing page
Create a clean international B2B landing page with strong hierarchy, product/application proof, manufacturing capability, quality assurance, and a clear inquiry CTA. Avoid exaggerated unsupported claims and generic “futuristic tech” visuals.
